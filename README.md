# Student Performance Analytics System

## Objective
To analyze student marks and attendance using Python.

## Technologies Used
- Python
- Pandas
- NumPy

## Dataset
The dataset contains 20 student records with roll number, name, marks in Python, Java and C++, and attendance.

## Features
- Calculate total marks
- Calculate average marks
- Assign grades to students
- Identify pass and fail students
- Find highest and lowest marks
- Analyze subject-wise performance
- Display top 3 performers
- Analyze student attendance

## Project Files
- `main.py` – Performs student performance analysis
- `functions.py` – Contains functions for total, average, grade and pass/fail
- `students.csv` – Contains student data

## Final Outcome
The project displays student results and class performance summary using Python, Pandas and NumPy.
